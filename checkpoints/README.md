# Pretrained weights

The OmniTumor checkpoint `omnitumor_v2_final.pth` (1.8 GB) is **not** stored in this repository.
GitHub caps single files at 100 MB, so the weights are hosted on the Hugging Face Hub under gated access:

<https://huggingface.co/datasets/fadefade/OmniTumorData/>

Request access on that page. Once approved, download the checkpoint and point `--resume` at it.
